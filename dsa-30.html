Array & Slice Memory Layout

Contiguous 64-bit Memory Blocks

In Go, a slice is a 24-byte header consisting of a pointer to a backing array, a length, and a capacity. Because elements are placed contiguously in memory, accessing s[i] requires only a single pointer addition: address = base + (i × elemSize), giving arrays O(1) random access.

Checkpoint Quiz · Day 7 Standard Library Interfaces
Which set of methods must a Go type implement to satisfy both sort.Interface and heap.Interface in the standard library?
Correct! In Go, heap.Interface embeds sort.Interface (which defines Len() int, Less(i, j int) bool, and Swap(i, j int)) and adds two more methods: Push(x any) and Pop() any. This allows Go heaps to operate directly on existing slices!
🔮 Predict The Output
What is the capacity of s after executing: 
s := make([]int, 3, 4)
s = append(s, 10)
s = append(s, 20)
Answer: cap(s) == 8!
Initial slice has len=3, cap=4. The first append(s, 10) fills the 4th slot without reallocation (len=4, cap=4). The second append(s, 20) exceeds capacity 4, causing the Go runtime to allocate a new backing array by doubling the capacity to 8 (for slices with < 256 elements).
