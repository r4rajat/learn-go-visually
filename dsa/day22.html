Minimum Spanning Trees

Connecting all vertices with minimum total edge weight. The Cut Property. Kruskal's algorithm combining edge sorting and Disjoint Set Union (DSU).

1. Concept & Go Memory Architecture

In Go, performance and memory efficiency stem from understanding value semantics versus pointer indirection. Observe how the runtime lays out the data structure in memory below:

Kruskal's Algorithm Flow: 1. Generate all pairwise edges 2. Sort edges by ascending weight 3. Iterate edges: if endpoints belong to different components (DSU), add to MST 4. Stop when V - 1 edges selected
2. Canonical Problem & Algorithm

🎯 Problem: Min Cost to Connect All Points (LeetCode 1584)

Given an array points representing coordinates, return the minimum cost to make all points connected using Manhattan distance.

Key Algorithmic Insight: Build complete graph edges with Manhattan weights, sort using `slices.SortFunc`, and apply Kruskal's with DSU until n - 1 edges are accepted.
day22_minimum_spanning_trees.go 
package main

import (
	"fmt"
	"math"
	"slices"
)

type MSTEdge struct {
	u, v, cost int
}

func minCostConnectPoints(points [][]int) int {
	n := len(points)
	var edges []MSTEdge

	for i := 0; i < n; i++ {
		for j := i + 1; j < n; j++ {
			cost := int(math.Abs(float64(points[i][0]-points[j][0]))) +
				int(math.Abs(float64(points[i][1]-points[j][1])))
			edges = append(edges, MSTEdge{i, j, cost})
		}
	}

	slices.SortFunc(edges, func(a, b MSTEdge) int {
		return a.cost - b.cost
	})

	parent := make([]int, n)
	for i := range parent {
		parent[i] = i
	}
	var find func(x int) int
	find = func(x int) int {
		if parent[x] != x {
			parent[x] = find(parent[x])
		}
		return parent[x]
	}

	totalCost, edgesCount := 0, 0
	for _, e := range edges {
		rootU, rootV := find(e.u), find(e.v)
		if rootU != rootV {
			parent[rootU] = rootV
			totalCost += e.cost
			edgesCount++
			if edgesCount == n-1 {
				break
			}
		}
	}
	return totalCost
}

func main() {
	pts := [][]int{{0, 0}, {2, 2}, {3, 10}, {5, 2}, {7, 0}}
	fmt.Println("Min MST cost:", minCostConnectPoints(pts)) // 20
}
