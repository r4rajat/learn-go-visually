Backtracking

State-space tree exploration with pruning. The universal template: Choose → Recurse → Unchoose. Slicing and copy mechanics in Go to prevent reference mutation bugs.

2. Canonical Problem

🎯 Problem: Subsets (LeetCode 78)

Given an integer array nums of unique elements, return all possible subsets (the power set).

Key Algorithmic Insight: At each decision point, make a copy of the current state (`subset := make([]int, len(curr)); copy(subset, curr)`) before appending to result slice.
3. Intuition & Mental Model

Backtracking is brute-force search with an 'undo' button. For generating all subsets, at each element we have two choices: include it or exclude it. The universal template is: Choose element &rarr; Recurse &rarr; Unchoose (pop element).

🪜 Step-by-Step Algorithmic Strategy

1
Maintain a current path slice and a result slice of slices.
2
At every call, append a deep copy of current path to result.
3
Loop from startIndex to end of nums.
4
Choose: append nums[i] to current path.
5
Explore: recursively call backtrack with startIndex = i + 1.
6
Unchoose: pop nums[i] by slicing `current = current[:len(current)-1]`.
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION subsets(nums):
    result = []
    backtrack(start = 0, current = [], result)
    RETURN result

FUNCTION backtrack(start, current, result):
    APPEND COPY_OF(current) TO result

    FOR i FROM start TO len(nums) - 1:
        current.append(nums[i])          // Choose
        backtrack(i + 1, current, result) // Explore
        current.pop()                    // Unchoose
⚠️ Common Pitfalls & Edge Cases
In Go, writing `result = append(result, current)` directly! Slices are references to backing arrays. When you pop from `current` later, it mutates previously stored subsets! Always `copy()`.

day16_backtracking.go 
package main

import "fmt"

func subsets(nums []int) [][]int {
	var result [][]int
	var curr []int

	var backtrack func(start int)
	backtrack = func(start int) {
		// Deep copy current buffer
		subset := make([]int, len(curr))
		copy(subset, curr)
		result = append(result, subset)

		for i := start; i < len(nums); i++ {
			curr = append(curr, nums[i]) // Choose
			backtrack(i + 1)             // Explore
			curr = curr[:len(curr)-1]    // Unchoose
		}
	}

	backtrack(0)
	return result
}

func main() {
	fmt.Println("Subsets of [1, 2]:", subsets([]int{1, 2}))
	// Output: [[], [1], [1, 2], [2]]
}
