Sliding Window Pattern

Fixed vs. variable size sliding windows over continuous slices and strings. Avoiding redundant inner loops by adjusting left and right pointers in linear time.

2. Canonical Problem

🎯 Problem: Longest Substring Without Repeating Characters (LeetCode 3)

Given a string s, find the length of the longest substring without repeating characters.

Key Algorithmic Insight: Keep track of last seen index of each character using a 256-int slice. When duplicate found at right, advance left = max(left, lastSeen[char] + 1).
3. Intuition & Mental Model

A sliding window expands with `right` pointer and contracts with `left` pointer. To find the longest substring without repeating characters, remember the last seen index of each character in an array. When a duplicate appears, jump `left` forward past the previous occurrence.

🪜 Step-by-Step Algorithmic Strategy

1
Create lastSeen array of size 256 initialized to -1.
2
Maintain left = 0 and maxLen = 0.
3
For right from 0 to len(s) - 1: if lastSeen[char] >= left, move left = lastSeen[char] + 1.
4
Update lastSeen[char] = right.
5
Update maxLen = max(maxLen, right - left + 1).
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION lengthOfLongestSubstring(s):
    lastSeen = ARRAY(size = 256, initial = -1)
    maxLen = 0, left = 0

    FOR right FROM 0 TO len(s) - 1:
        char = s[right]
        IF lastSeen[char] >= left:
            left = lastSeen[char] + 1
        lastSeen[char] = right
        maxLen = max(maxLen, right - left + 1)

    RETURN maxLen
⚠️ Common Pitfalls & Edge Cases
Forgetting the condition `lastSeen[char] >= left` before jumping `left`. Characters seen before the current window must not pull `left` backward!

day24_sliding_window_pattern.go 
package main

import "fmt"

func lengthOfLongestSubstring(s string) int {
	lastSeen := make([]int, 256)
	for i := range lastSeen {
		lastSeen[i] = -1
	}

	maxLen, left := 0, 0
	for right := 0; right < len(s); right++ {
		char := s[right]
		if lastSeen[char] >= left {
			left = lastSeen[char] + 1
		}
		lastSeen[char] = right
		if right-left+1 > maxLen {
			maxLen = right - left + 1
		}
	}
	return maxLen
}

func main() {
	fmt.Println("Longest len:", lengthOfLongestSubstring("abcabcbb")) // 3 ("abc")
}
