2. Canonical Problem

🎯 Problem: Search in Rotated Sorted Array (LeetCode 33)

Given a sorted array rotated at an unknown pivot, find the index of target in O(log n) runtime.

Key Algorithmic Insight: At every midpoint, at least one half of the array is guaranteed to be strictly sorted. Determine which half is sorted, then check if target is inside its boundaries.
3. Intuition & Mental Model

Binary search halves the search space at each comparison. In a rotated sorted array, splitting at midpoint always leaves at least ONE half cleanly sorted. Determine which half is sorted, check if target lies within its bounds, and discard the other half in O(log n).

🪜 Step-by-Step Algorithmic Strategy

1
Initialize low = 0 and high = len(nums) - 1.
2
Calculate mid = low + (high - low) / 2 to avoid integer overflow.
3
If nums[mid] == target, return mid.
4
Check if left half [low..mid] is sorted (nums[low] <= nums[mid]). If target is within [nums[low], nums[mid]], search left; else search right.
5
If right half is sorted, check if target is within [nums[mid], nums[high]]. If so search right; else search left.
6
Return -1 if low > high without finding target.
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION search(nums, target):
    low = 0, high = len(nums) - 1
    WHILE low <= high:
        mid = low + (high - low) / 2
        IF nums[mid] == target: RETURN mid

        IF nums[low] <= nums[mid]:   // Left half sorted
            IF target >= nums[low] AND target < nums[mid]:
                high = mid - 1
            ELSE:
                low = mid + 1
        ELSE:                        // Right half sorted
            IF target > nums[mid] AND target <= nums[high]:
                low = mid + 1
            ELSE:
                high = mid - 1

    RETURN -1
⚠️ Common Pitfalls & Edge Cases
Writing `mid = (low + high) / 2` which can cause integer overflow when numbers are large. Always write `mid = low + (high - low) / 2`.

package main

import "fmt"

func search(nums []int, target int) int {
	low, high := 0, len(nums)-1

	for low <= high {
		mid := low + (high-low)/2
		if nums[mid] == target {
			return mid
		}

		// Check if left half is sorted
		if nums[low] <= nums[mid] {
			if target >= nums[low] && target < nums[mid] {
				high = mid - 1
			} else {
				low = mid + 1
			}
		} else { // Right half is sorted
			if target > nums[mid] && target <= nums[high] {
				low = mid + 1
			} else {
				high = mid - 1
			}
		}
	}
	return -1
}

func main() {
	nums := []int{4, 5, 6, 7, 0, 1, 2}
	fmt.Println("Index of 0:", search(nums, 0)) // 4
}
