Shortest Paths (Dijkstra)

Single-source shortest paths on weighted graphs. Dijkstra's greedy edge relaxation algorithm using standard library `container/heap`. Bellman-Ford for negative edge weights.

1. Concept & Visual Architecture

Key Takeaway: Dijkstra relaxes edge weights greedily using a Min-Heap. Shortest path to Target T is S → B → T (weight 3) rather than S → A → T (weight 9).

2. Canonical Problem

🎯 Problem: Network Delay Time (LeetCode 743)

You are given a network of n nodes and directed weighted edges. Return the minimum time for a signal sent from node k to reach all nodes.

Key Algorithmic Insight: Use Dijkstra's algorithm. Maintain a min-heap of (distance, node). Pop minimum distance node; if not visited, relax its outgoing edges.
3. Intuition & Mental Model

Dijkstra finds the shortest path in weighted graphs with non-negative edges. It is greedy: maintain a priority queue of (distance, node). Always pop the closest unvisited node; its shortest distance is now finalized. Relax its outgoing neighbors.

🪜 Step-by-Step Algorithmic Strategy

1
Build adjacency list map[int][]Edge from times.
2
Maintain dist map and a min-heap initialized with (0, startNode).
3
While heap is non-empty: pop (d, u). If u is already in dist, skip.
4
Record dist[u] = d. For each neighbor (v, weight), push (d + weight, v) to heap.
5
If len(dist) < n, some nodes are unreachable (return -1). Otherwise return max(dist).
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION dijkstra(times, n, k):
    dist = MAP()
    pq = MIN_HEAP_WITH((dist=0, node=k))

    WHILE pq IS NOT EMPTY:
        (d, u) = POP_MIN(pq)
        IF u IN dist: CONTINUE
        dist[u] = d
        FOR EACH (v, weight) IN adj[u]:
            IF v NOT IN dist:
                PUSH(pq, (d + weight, v))

    RETURN MAX(dist) IF len(dist) == n ELSE -1
⚠️ Common Pitfalls & Edge Cases
Dijkstra does not work on graphs with negative edge weights (infinite loop or wrong result). Use Bellman-Ford for negative weights.

day21_shortest_paths_(dijkstra).go 
package main

import (
	"container/heap"
	"fmt"
)

type Edge struct {
	to, weight int
}

type NodeDist struct {
	id, dist int
}

type PQ []NodeDist

func (pq PQ) Len() int           { return len(pq) }
func (pq PQ) Less(i, j int) bool { return pq[i].dist < pq[j].dist }
func (pq PQ) Swap(i, j int)      { pq[i], pq[j] = pq[j], pq[i] }
func (pq *PQ) Push(x any)        { *pq = append(*pq, x.(NodeDist)) }
func (pq *PQ) Pop() any {
	old := *pq
	n := len(old)
	it := old[n-1]
	*pq = old[:n-1]
	return it
}

func networkDelayTime(times [][]int, n int, k int) int {
	adj := make(map[int][]Edge)
	for _, t := range times {
		adj[t[0]] = append(adj[t[0]], Edge{t[1], t[2]})
	}

	dist := make(map[int]int)
	pq := &PQ{{k, 0}}
	heap.Init(pq)

	for pq.Len() > 0 {
		curr := heap.Pop(pq).(NodeDist)
		if _, exists := dist[curr.id]; exists {
			continue
		}
		dist[curr.id] = curr.dist

		for _, e := range adj[curr.id] {
			if _, visited := dist[e.to]; !visited {
				heap.Push(pq, NodeDist{e.to, curr.dist + e.weight})
			}
		}
	}

	if len(dist) < n {
		return -1
	}
	maxTime := 0
	for _, d := range dist {
		if d > maxTime {
			maxTime = d
		}
	}
	return maxTime
}

func main() {
	times := [][]int{{2, 1, 1}, {2, 3, 1}, {3, 4, 1}}
	fmt.Println("Delay time:", networkDelayTime(times, 4, 2)) // 2
}
