2. Canonical Problem

🎯 Problem: Validate Binary Search Tree (LeetCode 98)

Given the root of a binary tree, determine if it is a valid binary search tree (BST).

Key Algorithmic Insight: Every node must satisfy min < node.Val < max. When recursing left, update max; when recursing right, update min.
3. Intuition & Mental Model

A Binary Search Tree maintains a global invariant: every node in the left subtree must be smaller than the root, and every node in the right subtree must be greater. It is a common mistake to only compare a node against its immediate children! We must carry allowable valid boundaries [min, max] down the tree as we recurse.

🪜 Step-by-Step Algorithmic Strategy

1
Create a recursive helper function validate(node, minBound, maxBound).
2
A nil node is a valid BST (base case, return true).
3
If minBound is non-nil and node.Val <= *minBound, return false.
4
If maxBound is non-nil and node.Val >= *maxBound, return false.
5
Recurse left: validate(node.Left, minBound, node.Val).
6
Recurse right: validate(node.Right, node.Val, maxBound).
7
Return true only if both left and right subtrees are valid.
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION isValidBST(root):
    RETURN validate(root, minBound = nil, maxBound = nil)

FUNCTION validate(node, minBound, maxBound):
    IF node IS nil:
        RETURN true
    IF minBound != nil AND node.Val <= minBound:
        RETURN false
    IF maxBound != nil AND node.Val >= maxBound:
        RETURN false

    RETURN validate(node.Left, minBound, node.Val) AND
           validate(node.Right, node.Val, maxBound)
⚠️ Common Pitfalls & Edge Cases
Only checking `node.Left.Val < node.Val` locally. For example: tree [10, 5, 15, nil, nil, 6, 20] has 6 in right subtree of 10, which violates BST rules even though 6 < 15 locally!

day06_binary_trees_and_bsts.go 
package main

import "fmt"

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

func isValidBST(root *TreeNode) bool {
	var validate func(node *TreeNode, minVal, maxVal *int) bool
	validate = func(node *TreeNode, minVal, maxVal *int) bool {
		if node == nil {
			return true
		}
		if minVal != nil && node.Val <= *minVal {
			return false
		}
		if maxVal != nil && node.Val >= *maxVal {
			return false
		}
		return validate(node.Left, minVal, &node.Val) &&
			validate(node.Right, &node.Val, maxVal)
	}
	return validate(root, nil, nil)
}

func main() {
	tree := &TreeNode{
		Val:   10,
		Left:  &TreeNode{Val: 5},
		Right: &TreeNode{Val: 15},
	}
	fmt.Println("Is valid BST:", isValidBST(tree)) // true
}
