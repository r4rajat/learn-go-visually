2. Canonical Problem

🎯 Problem: Find if Path Exists in Graph (LeetCode 1971)

Given an undirected graph with n vertices and a list of edges, determine if there is a valid path from source to destination.

Key Algorithmic Insight: Build the adjacency list, then traverse from source using a BFS queue and a visited boolean slice.
3. Intuition & Mental Model

Graphs model connections between entities. We represent graphs using an Adjacency List: a map where each key is a node and its value is a slice of connected neighbors. To find if a path exists between source and destination, we start at source and search outward using a queue (BFS).

🪜 Step-by-Step Algorithmic Strategy

1
If source == destination, return true immediately.
2
Build adjacency list map[int][]int from the edge list (bidirectional for undirected graphs).
3
Maintain a visited []bool slice of size n to avoid infinite cycles.
4
Enqueue source and mark it visited.
5
While queue is non-empty, dequeue node. If it matches destination, return true. Otherwise enqueue unvisited neighbors.
6
If queue empties without reaching destination, return false.
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION validPath(n, edges, source, destination):
    IF source == destination: RETURN true
    adj = BUILD_ADJACENCY_LIST(edges, bidirectional = true)
    visited = ARRAY_OF_BOOLEANS(size = n, initial = false)

    queue = [source]
    visited[source] = true

    WHILE queue IS NOT EMPTY:
        curr = DEQUEUE(queue)
        IF curr == destination: RETURN true
        FOR EACH neighbor IN adj[curr]:
            IF NOT visited[neighbor]:
                visited[neighbor] = true
                ENQUEUE(queue, neighbor)

    RETURN false
⚠️ Common Pitfalls & Edge Cases
Forgetting that undirected edges must be added in BOTH directions: `adj[u] = append(adj[u], v)` AND `adj[v] = append(adj[v], u)`. Forgetting the `visited` check, causing infinite loops in cyclic graphs.

package main

import "fmt"

func validPath(n int, edges [][]int, source int, destination int) bool {
	if source == destination {
		return true
	}
	adj := make(map[int][]int, n)
	for _, e := range edges {
		adj[e[0]] = append(adj[e[0]], e[1])
		adj[e[1]] = append(adj[e[1]], e[0])
	}

	visited := make([]bool, n)
	visited[source] = true
	queue := []int{source}

	for len(queue) > 0 {
		curr := queue[0]
		queue = queue[1:]

		if curr == destination {
			return true
		}
		for _, nxt := range adj[curr] {
			if !visited[nxt] {
				visited[nxt] = true
				queue = append(queue, nxt)
			}
		}
	}
	return false
}

func main() {
	edges := [][]int{{0, 1}, {1, 2}, {2, 0}}
	fmt.Println("Path exists (0->2):", validPath(3, edges, 0, 2)) // true
}
