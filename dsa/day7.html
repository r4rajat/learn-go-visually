2. Canonical Problem

🎯 Problem: Top K Frequent Elements (LeetCode 347)

Given an integer array nums and an integer k, return the k most frequent elements using a min-heap.

Key Algorithmic Insight: Count frequencies with a map, then push into a Min-Heap of size k. If heap size exceeds k, pop the minimum frequency. Leaves top-k elements in O(n log k) time.
3. Intuition & Mental Model

If you sort the whole array to find top k elements, it takes O(n log n). But we only care about the top k! By maintaining a Min-Heap of size k, the root of the heap always holds the k-th most frequent element. Whenever the heap grows beyond k, we drop the smallest frequency. At the end, only the top k elements remain in O(n log k) time!

🪜 Step-by-Step Algorithmic Strategy

1
Count frequency of each number using a Go map[int]int.
2
Define a MinHeap struct that implements heap.Interface (Len, Less, Swap, Push, Pop).
3
Iterate through map entries and Push (num, count) into the heap.
4
If heap size exceeds k, immediately Pop the minimum element.
5
Extract the remaining k elements into a result slice.
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION topKFrequent(nums, k):
    freqMap = COUNT_ELEMENTS(nums)
    minHeap = EMPTY_MIN_HEAP()

    FOR EACH (val, count) IN freqMap:
        PUSH(minHeap, Item(val, count))
        IF SIZE(minHeap) > k:
            POP_MIN(minHeap)  // Evict the element with smallest frequency

    RETURN EXTRACT_VALUES(minHeap)
⚠️ Common Pitfalls & Edge Cases
Using a Max-Heap instead of a Min-Heap. With a Max-Heap, popping drops the largest elements, which defeats the purpose! A Min-Heap keeps the largest elements safe at the bottom.

day07_heaps_and_priority_queues.go 
package main

import (
	"container/heap"
	"fmt"
)

type Item struct {
	val, count int
}

type MinHeap []Item

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i].count < h[j].count }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x any)        { *h = append(*h, x.(Item)) }
func (h *MinHeap) Pop() any {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[:n-1]
	return x
}

func topKFrequent(nums []int, k int) []int {
	freq := make(map[int]int)
	for _, n := range nums {
		freq[n]++
	}

	h := &MinHeap{}
	heap.Init(h)

	for val, count := range freq {
		heap.Push(h, Item{val, count})
		if h.Len() > k {
			heap.Pop(h)
		}
	}

	result := make([]int, k)
	for i := k - 1; i >= 0; i-- {
		result[i] = heap.Pop(h).(Item).val
	}
	return result
}

func main() {
	fmt.Println("Top 2 frequent:", topKFrequent([]int{1, 1, 1, 2, 2, 3}, 2)) // [1, 2]
}
