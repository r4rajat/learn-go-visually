System Design & DSA in Production

Bridging abstract DSA and distributed infrastructure. Thread-safe LRU Cache combining `container/list` doubly-linked list with Go `map` and `sync.RWMutex`.

2. Canonical Problem

🎯 Problem: Thread-Safe LRU Cache Implementation (LeetCode 146)

Design a data structure that follows the constraints of a Least Recently Used (LRU) cache with O(1) Get and Put operations that is safe for concurrent access.

Key Algorithmic Insight: Map provides O(1) key lookup. Doubly-linked list allows O(1) eviction of oldest element and O(1) promotion to head. sync.RWMutex guards concurrent goroutines.
3. Intuition & Mental Model

An LRU Cache combines a Hash Map for O(1) key lookups and a Doubly Linked List for O(1) eviction of the least recently used element and O(1) promotion of accessed elements to the front. To make it production ready in Go, wrap operations in `sync.RWMutex`.

🪜 Step-by-Step Algorithmic Strategy

1
Define LRUCache with capacity, map[int]*list.Element, *list.List, and sync.RWMutex.
2
Get(key): Lock mutex, check map. If found, list.MoveToFront(elem) and return value.
3
Put(key, val): Lock mutex. If key exists, update value and MoveToFront.
4
If key is new: if size >= capacity, evict list.Back() and delete its key from map.
5
PushFront new entry and store in map.
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
CLASS LRUCache:
    capacity, map, list, mutex

FUNCTION Get(key):
    LOCK(mutex)
    IF key IN map:
        MOVE_TO_FRONT(list, map[key])
        RETURN map[key].value
    RETURN -1

FUNCTION Put(key, value):
    LOCK(mutex)
    IF key IN map:
        UPDATE AND MOVE_TO_FRONT
    ELSE:
        IF len(list) >= capacity:
            EVICT(list.Back(), map)
        INSERT_FRONT(list, map, key, value)
⚠️ Common Pitfalls & Edge Cases
Forgetting to delete the evicted element from `map` when removing from `list`, causing memory leaks and capacity desynchronization.

day28_system_design_and_dsa_in_production.go 
package main

import (
	"container/list"
	"fmt"
	"sync"
)

type CacheItem struct {
	key, value int
}

type LRUCache struct {
	capacity int
	items    map[int]*list.Element
	list     *list.List
	mu       sync.RWMutex
}

func NewLRUCache(capacity int) *LRUCache {
	return &LRUCache{
		capacity: capacity,
		items:    make(map[int]*list.Element),
		list:     list.New(),
	}
}

func (c *LRUCache) Get(key int) int {
	c.mu.Lock()
	defer c.mu.Unlock()

	if elem, ok := c.items[key]; ok {
		c.list.MoveToFront(elem)
		return elem.Value.(CacheItem).value
	}
	return -1
}

func (c *LRUCache) Put(key int, value int) {
	c.mu.Lock()
	defer c.mu.Unlock()

	if elem, ok := c.items[key]; ok {
		elem.Value = CacheItem{key, value}
		c.list.MoveToFront(elem)
		return
	}

	if c.list.Len() >= c.capacity {
		oldest := c.list.Back()
		if oldest != nil {
			delete(c.items, oldest.Value.(CacheItem).key)
			c.list.Remove(oldest)
		}
	}

	c.items[key] = c.list.PushFront(CacheItem{key, value})
}

func main() {
	cache := NewLRUCache(2)
	cache.Put(1, 100)
	cache.Put(2, 200)
	fmt.Println("Get 1:", cache.Get(1)) // 100 (1 is promoted)
	cache.Put(3, 300)                  // Evicts 2
	fmt.Println("Get 2:", cache.Get(2)) // -1 (evicted!)
}
