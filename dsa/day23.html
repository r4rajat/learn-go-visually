Topological Sort & DAGs

Linear ordering of vertices in Directed Acyclic Graphs (DAGs). Kahn's in-degree BFS queue algorithm and cycle detection. Real-world applications in build dependencies.

2. Canonical Problem

🎯 Problem: Course Schedule II (LeetCode 210)

Return the ordering of courses you should take to finish all courses given prerequisite pairs. If impossible, return an empty array.

Key Algorithmic Insight: Track in-degrees of every course. Push courses with 0 prerequisites into a queue. As each is completed, decrement dependent in-degrees. If order length < n, cycle exists!
3. Intuition & Mental Model

Topological sort orders tasks with dependencies (Directed Acyclic Graphs). Kahn's Algorithm tracks in-degrees (number of prerequisites). Courses with in-degree 0 can be taken immediately. Completing them decrements dependent in-degrees.

🪜 Step-by-Step Algorithmic Strategy

1
Build adjacency list and inDegree slice of size numCourses.
2
Enqueue all courses with inDegree == 0.
3
While queue is non-empty: pop course, append to order slice.
4
Decrement inDegree of all dependent courses. If a dependent reaches 0, enqueue it.
5
If len(order) == numCourses, return order; otherwise return nil (cycle detected!).
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION findOrder(numCourses, prerequisites):
    inDegree = ARRAY_OF_ZEROS(numCourses)
    adj = BUILD_GRAPH(prerequisites, inDegree)
    queue = [all courses where inDegree == 0]
    order = []

    WHILE queue IS NOT EMPTY:
        curr = DEQUEUE(queue)
        order.append(curr)
        FOR EACH nextCourse IN adj[curr]:
            inDegree[nextCourse]--
            IF inDegree[nextCourse] == 0:
                ENQUEUE(queue, nextCourse)

    RETURN order IF len(order) == numCourses ELSE nil
⚠️ Common Pitfalls & Edge Cases
Returning an invalid partial order when a cycle exists. Always verify `len(order) == numCourses`.

package main

import "fmt"

func findOrder(numCourses int, prerequisites [][]int) []int {
	adj := make(map[int][]int, numCourses)
	inDegree := make([]int, numCourses)

	for _, p := range prerequisites {
		course, pre := p[0], p[1]
		adj[pre] = append(adj[pre], course)
		inDegree[course]++
	}

	queue := make([]int, 0)
	for i := 0; i < numCourses; i++ {
		if inDegree[i] == 0 {
			queue = append(queue, i)
		}
	}

	order := make([]int, 0, numCourses)
	for len(queue) > 0 {
		curr := queue[0]
		queue = queue[1:]
		order = append(order, curr)

		for _, nxt := range adj[curr] {
			inDegree[nxt]--
			if inDegree[nxt] == 0 {
				queue = append(queue, nxt)
			}
		}
	}

	if len(order) == numCourses {
		return order
	}
	return nil // Cycle detected
}

func main() {
	reqs := [][]int{{1, 0}, {2, 0}, {3, 1}, {3, 2}}
	fmt.Println("Course order:", findOrder(4, reqs)) // [0, 1, 2, 3] or [0, 2, 1, 3]
}
