2. Canonical Problem

🎯 Problem: Kth Largest Element in an Array (LeetCode 215)

Given an integer array nums and an integer k, return the kth largest element in the array using Quickselect.

Key Algorithmic Insight: Quickselect only recurses into the partition containing the target index (len - k), dropping the average time complexity from O(n log n) to O(n).
3. Intuition & Mental Model

Sorting the entire array to find the k-th largest element takes O(n log n). Quickselect uses the partitioning mechanism of QuickSort: place a pivot into its correct final sorted index p. If p is our target index (len - k), we are done! If p < target, we only recurse right; otherwise we only recurse left. Average time: O(n)!

🪜 Step-by-Step Algorithmic Strategy

1
Target index is len(nums) - k (the index if array were fully sorted).
2
Pick a pivot (e.g. nums[right]).
3
Partition the sub-array so elements <= pivot go to left, > pivot go to right.
4
If pivot lands at target, return nums[pivot].
5
If pivot is left of target, recurse on right half; otherwise recurse on left half.
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION findKthLargest(nums, k):
    target = len(nums) - k
    RETURN quickSelect(nums, 0, len(nums) - 1, target)

FUNCTION quickSelect(nums, left, right, target):
    pivotIndex = partition(nums, left, right)
    IF pivotIndex == target:
        RETURN nums[pivotIndex]
    ELSE IF pivotIndex < target:
        RETURN quickSelect(nums, pivotIndex + 1, right, target)
    ELSE:
        RETURN quickSelect(nums, left, pivotIndex - 1, target)
⚠️ Common Pitfalls & Edge Cases
Confusing k-th largest with k-th smallest. The 1st largest is the maximum element at index `len - 1`.

package main

import "fmt"

func findKthLargest(nums []int, k int) int {
	target := len(nums) - k

	var quickSelect func(l, r int) int
	quickSelect = func(l, r int) int {
		pivot := nums[r]
		p := l
		for i := l; i < r; i++ {
			if nums[i] <= pivot {
				nums[p], nums[i] = nums[i], nums[p]
				p++
			}
		}
		nums[p], nums[r] = nums[r], nums[p]

		if p == target {
			return nums[p]
		}
		if p < target {
			return quickSelect(p+1, r)
		}
		return quickSelect(l, p-1)
	}

	return quickSelect(0, len(nums)-1)
}

func main() {
	nums := []int{3, 2, 1, 5, 6, 4}
	fmt.Println("2nd largest:", findKthLargest(nums, 2)) // 5
}
