Two Pointers Technique

Opposite-direction converging pointers (Two Sum II, Container With Most Water), same-direction read/write pointers, and fast/slow pointer cycle detection.

1. Concept & Visual Architecture

2. Canonical Problem

🎯 Problem: Container With Most Water (LeetCode 11)

Given n non-negative integers representing vertical lines, find two lines that together with the x-axis form a container holding the most water.

Key Algorithmic Insight: Width shrinks with every step. To find a larger area, always move the pointer pointing to the shorter wall inward.
3. Intuition & Mental Model

Container area is width * min(height[left], height[right]). Moving the taller wall inward can only decrease width without increasing height. Therefore, the ONLY way to potentially find a larger area is to move the shorter wall inward!

🪜 Step-by-Step Algorithmic Strategy

1
Initialize left = 0 and right = len(height) - 1.
2
Calculate current area: min(height[left], height[right]) * (right - left).
3
Update maxWater.
4
If height[left] < height[right], increment left; otherwise decrement right.
5
Terminate when left == right.
4. Structured Pseudocode

Before looking at Go syntax, study the language-agnostic logic. Trace this mentally with sample inputs:

Algorithm Pseudocode Language Independent 
FUNCTION maxArea(height):
    left = 0, right = len(height) - 1
    maxWater = 0

    WHILE left < right:
        h = min(height[left], height[right])
        w = right - left
        maxWater = max(maxWater, h * w)
        IF height[left] < height[right]:
            left++
        ELSE:
            right--

    RETURN maxWater
⚠️ Common Pitfalls & Edge Cases
Off-by-one errors on width calculation: width is `right - left`, NOT `right - left + 1`.

day25_two_pointers_technique.go 
package main

import "fmt"

func maxArea(height []int) int {
	left, right := 0, len(height)-1
	maxWater := 0

	for left < right {
		h := min(height[left], height[right])
		w := right - left
		if h*w > maxWater {
			maxWater = h * w
		}
		if height[left] < height[right] {
			left++
		} else {
			right--
		}
	}
	return maxWater
}

func main() {
	heights := []int{1, 8, 6, 2, 5, 4, 8, 3, 7}
	fmt.Println("Max Area:", maxArea(heights)) // 49
}
